# Argon — Feature Ideas

## High-value, low-effort

- [ ] **Rate/Love track** — Heart button in display or bottom bar. Apple Music supports `loved`/`disliked` via AppleScript.
- [ ] **Dynamic bitrate/sample rate** — Replace hardcoded "256 KBPS / 44 KHZ" with real values from Apple Music (`bit rate`, `sample rate` on current track).
- [ ] **Playlist toggle in bottom bar** — Add a PL button (like Winamp) so the playlist viewer is accessible without needing a theme to enable it.
- [ ] **Double-click titlebar to windowshade** — Classic Winamp behavior. Double-clicking the titlebar toggles windowshade mode.

## Medium effort, high character

- [ ] **Live theme preview on hover** — Preview theme colors on the player when hovering a theme card, revert on mouse leave.
- [ ] **Marquee click interaction** — Click to pause/resume scroll or change direction, like Winamp.
- [ ] **Track elapsed/remaining toggle** — Click the time display to toggle between elapsed and remaining time.
- [ ] **Visualizer responds to playback state** — Go silent when paused, animate when playing. Make the fake data feel connected to transport state.

## Bigger lifts

- [ ] **Media key preference toggle** — Global shortcuts steal MediaPlayPause/Next/Prev from other apps. Make this a user preference.
- [ ] **Winamp skin (.wsz) palette import** — Extract color palettes from classic Winamp .wsz skin files and auto-generate Argon themes from them.
